# Retail Sales Analysis Dashboard

## Project Overview
An interactive retail sales analysis dashboard developed using Microsoft Excel.

## Dataset
- 500 fictional orders
- 100 customers
- 20 products

## Tools & Techniques
- Microsoft Excel
- XLOOKUP
- Excel formulas
- PivotTables and PivotCharts
- Slicers and Timelines
- Data cleaning and validation

## Dashboard Features
- Total Revenue
- Total Orders
- Average Order Value
- Highest and Lowest Order Value
- Total Quantity Sold
- Revenue analysis by category, region, product and month
- Interactive filters

## Key Insights
- Electronics generated the highest category revenue.
- West was the highest-revenue region.
- October was the strongest sales month.
- Laptops were the top revenue-generating product.

## Note
This project uses fictional data for educational and portfolio purposes.
